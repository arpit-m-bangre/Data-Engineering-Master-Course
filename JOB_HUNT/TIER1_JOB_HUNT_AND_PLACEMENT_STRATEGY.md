```text

         │
```

---

### 📌 STAGE 1: ENTERPRISE SQL LIVE CODING ROUND (45–60 Mins)
* **What they test:** CTEs, Window Ranking (`ROW_NUMBER`, `DENSE_RANK`), Multi-Table ANSI Joins, `HAVING` vs `WHERE`, NULL handling in aggregations, In-Place Deduplication.
* **Winning Strategy:**
  1. State your logic out loud BEFORE writing the first line of SQL.
  2. Ask edge-case questions: *"Are there duplicate primary keys? How should ties be broken? Can foreign keys contain NULLs?"*
  3. Write clean, UPPERCASE SQL keywords with formatted aliases.

---

### 📌 STAGE 2: PYTHON, OOP & PYSPARK ENGINE (45–60 Mins)
* **What they test:** Pandas transformations, custom pipeline classes, generator-based chunking, PySpark DataFrames, partitioning strategies, broadcast joins.
* **Winning Strategy:**
  - Avoid brute-force in-memory loading on large datasets. Explain chunking (`chunksize=10000`) and distributed execution plans (`explain()`).

---

### 📌 STAGE 3: DATA SYSTEM DESIGN & WAREHOUSING (60 Mins)
* **What they test:** Star Schema vs Snowflake Schema, Fact vs Dimension tables, Slowly Changing Dimensions (SCD Type 1 & 2), Partitioning & Clustering, Medallion Architecture (Bronze -> Silver -> Gold).
* **Winning Strategy:**
  - Draw the pipeline architecture clearly: Ingestion (Kafka/API) -> Raw Zone (S3/ADLS) -> Cleansed Transform (Spark/dbt) -> Warehouse (Snowflake/Redshift) -> Serving Layer / BI.
