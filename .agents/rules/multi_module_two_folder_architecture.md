# 🏛️ Multi-Module 2-Folder Ultra-Lean Architecture & 5-Pillar Standard

This rule governs **Module 03 (ETL)** and **ALL upcoming modules** (`02_PYTHON`, `04_PYSPARK_BIG_DATA`, `05_DATA_WAREHOUSING`, `06_CLOUD_ENGINEERING`, `07_ORCHESTRATION`) across all current and future sessions.

---

## 1. The 2-Folder Ultra-Lean Law (Zero Fragmentation)
Every upcoming module MUST have strictly **two working directories**:
1. **`01_CLASS_AND_REVISION/`**: 
   - Unified single daily file (`YYYY-MM-DD_<TOPIC>.md`).
   - Combines high-yield class notes, code blueprints, 5-Pillar revision, and mental models.
2. **`02_TASKS_AND_DRILLS/`**: 
   - Unified single daily practice file (`YYYY-MM-DD_TASKS_AND_DRILLS.md`).
   - Combines Faculty In-Class Design Challenges (Part 1) + 14 Targeted Practice Drills (Part 2) with blank answer templates.

*(Note: Module 01 SQL retains its classic multi-tier format to preserve completed historical work).*

---

## 2. The 5-Pillar High-Yield Precision Framework
All Tier 1 notes in ETL and future modules MUST follow the **5-Pillar Standard**:
- **Pillar 1: North Star & Real-World Analogies** (Conversational, simple plain-English, 2-3 vivid everyday analogies).
- **Pillar 2: Architectural Blueprint & Trade-Off Matrix** (Clean ASCII pipeline flow + side-by-side comparative table).
- **Pillar 3: Production Code Blueprint** (Executable, robust, uppercase T-SQL/Python with error handling & idempotency).
- **Pillar 4: 5 Deadly Production Failures & Senior DE Fixes** (Concrete failure at scale + exact senior resolution).
- **Pillar 5: Tier-1 Interview Knockout Q&A** (Top interview questions asked by Tier-1 product firms + winning model answers).

---

## 3. The 75–90 Minute Daily Velocity Law
Each class day's study workflow is strictly capped at **75–90 minutes max**:
- **10–15 mins:** Fast Mental Read (5 Pillars in `01_CLASS_AND_REVISION/`)
- **15 mins:** Native Code Execution / Typing in IDE/Studio
- **20 mins:** Faculty In-Class Challenge (`02_TASKS_AND_DRILLS/` Part 1)
- **30 mins:** 14 Targeted Drills Solution (`02_TASKS_AND_DRILLS/` Part 2)

---

## 4. Dual-Fleet Operating Sequence (Pippo-First 09:00 AM)
- **Pippo Fleet (09:00 AM Morning Priority):** Fast academic foundation, 5-Pillar mastery, faculty challenges, and 14 drills.
- **WALL-E Fleet (Afternoon Enterprise Simulation):** Heavy industrial building (NexusFin), cluster internals, IOPS sizing, LeetCode drills, and LinkedIn authority.
