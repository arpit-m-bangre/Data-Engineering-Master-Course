## STEP 1 — QUICK RECALL

### Recall Questions
1. Why is `TRUNCATE TABLE` classified as a DDL command whereas `DELETE FROM table` is DML?
2. Can a `WHERE` clause be applied with `TRUNCATE TABLE`?
3. What happens if you try to decrease a column's `VARCHAR` size below the length of data currently stored in that column?
4. What system stored procedure is used in SQL Server to rename tables or columns?

### Answers & Explanations
1. **Command Types**: `DELETE` targets individual rows (DML); `TRUNCATE` resets the table data pages/allocations at the schema structural level (DDL).
2. **`WHERE` with `TRUNCATE`**: No. `TRUNCATE` removes all rows indiscriminately and does not support a `WHERE` clause.
3. **Decreasing Column Size**: SQL Server throws a string truncation error ("String or binary data would be truncated") and aborts the `ALTER COLUMN` command.
4. **Renaming Procedure**: `EXEC sp_rename 'OldName', 'NewName';`

## STEP 2 — CONCEPT UNDERSTANDING

### Topic 1: `DELETE` vs `TRUNCATE` vs `DROP`

| Feature | `DELETE` | `TRUNCATE` | `DROP` |
| :--- | :--- | :--- | :--- |
| **Command Category** | DML | DDL | DDL |
| **What it Removes** | Selected or all rows | All rows only | Table structure AND data |
| **Supports `WHERE`?** | Yes | No | No |
| **Table Structure Stays?** | Yes | Yes | No |
| **Execution Speed** | Slower (Row-by-row logging) | Fast (Deallocates pages) | Fast (Drops schema object) |

### Topic 2: `ALTER TABLE` Operations
- **`ADD` Column**: Adds new fields initialized to `NULL` (or default values).
- **`DROP COLUMN`**: Permanently removes structural attributes and their underlying data.
- **`ALTER COLUMN`**: Modifies data type specifications or changes character length limits.

## STEP 3 — SQL SYNTAX & CODE EXAMPLES

```sql
-- 1. ALTER TABLE ADD Columns
ALTER TABLE employee1
ADD city VARCHAR(10), age INT, marks INT;

-- 2. ALTER TABLE DROP COLUMN
ALTER TABLE employee1
DROP COLUMN city, marks;

-- 3. ALTER TABLE ALTER COLUMN (Data Type / Size Change)
ALTER TABLE employee1
ALTER COLUMN empname VARCHAR(60);

-- 4. Renaming Table and Column via sp_rename
EXECUTE sp_rename 'employee1', 'emp';
EXECUTE sp_rename 'emp.dept', 'org_id';
```

## STEP 5 — COMMON MISTAKES & DEBUGGING

### Buggy Query 1
```sql
-- Bug: Attempting to use TRUNCATE with WHERE clause
TRUNCATE TABLE employee1 WHERE empid = 101;
```
- **Correction**: `TRUNCATE` does not accept a `WHERE` clause. Use `DELETE` for conditional row removal.
```sql
DELETE FROM employee1 WHERE empid = 101;
```

### Buggy Query 2
```sql
-- Bug: Missing table prefix when renaming columns with sp_rename
EXEC sp_rename 'dept', 'org_id';
```
- **Correction**: When renaming a column, you must qualify it with the table name: `'TableName.OldColumnName'`.
```sql
EXEC sp_rename 'emp.dept', 'org_id';
```

## STEP 6 — REAL-WORLD DATA ENGINEERING APPLICATION

**Scenario**: Schema migration pipeline adding tracking columns to legacy tables.
- **Required Info**: Target table name and new metadata column definitions.
- **Approach**: Execute DDL `ALTER TABLE ADD` statements, then run DML `UPDATE` scripts to backfill existing records with default values:
```sql
ALTER TABLE Orders ADD IngestionTimestamp DATETIME;
UPDATE Orders SET IngestionTimestamp = GETDATE() WHERE IngestionTimestamp IS NULL;
```

## STEP 7 — MINI ASSESSMENT

### Questions
1. Write a statement to add a `gender` column of data type `CHAR(1)` to `employee1`.
2. Write a statement to drop the `gender` column from `employee1`.
3. Which SQL command is fastest to delete 1,000,000 rows without dropping the table structure?

### Solutions
```sql
-- 1. ADD Column
ALTER TABLE employee1 ADD gender CHAR(1);

-- 2. DROP Column
ALTER TABLE employee1 DROP COLUMN gender;

-- 3. Answer: TRUNCATE TABLE employee1;
```
