## 🧠 STEP 1 — QUICK RECALL

### ❓ Recall Questions
1. If you run `UPDATE emp SET salary = 1000` without a `WHERE` clause, what happens?
2. Is `UPDATE` a DML or DDL command?
3. Can you use `ALTER TABLE` to change the spelling of an existing row's name?
4. What happens to existing data in a column if you use `ALTER TABLE ... ALTER COLUMN` to change its data type from `VARCHAR(100)` to `INT`?

### 🗝️ Answers & Explanations
1. **The Mass Update Disaster**: It updates every single row in the entire table! If you have 1 million employees, they all suddenly make $1000.
2. **Command Category**: `UPDATE` only messes with the furniture (data), not the house structure, so it is a **DML** (Data Manipulation Language) command.
3. **`ALTER TABLE` Purpose**: No! `ALTER TABLE` is for renovating the house structure (like adding a new room/column). To change a person's name (data), you must use `UPDATE`.
4. **Data Type Conversion**: The database tries to convert the text into numbers. If even one person has the name "Arpit" in that column, the conversion fails because "Arpit" cannot become an `INT`!

## 🧠 STEP 2 — CONCEPT UNDERSTANDING

### Topic 1: The `UPDATE` Command (The Magical Eraser)
- **What it means**: You don't need to delete a row and insert a new one just because someone got a raise. You use `UPDATE` to magically erase the old number and write a new one!
- **The Golden Rule**: ALWAYS use the Sniper Scope (`WHERE` clause) when using `UPDATE`. If you forget, you will accidentally update the entire company.

### Topic 2: The `ALTER TABLE` Command (The House Renovator)
- **What it means**: Your table is already built, but suddenly the boss says, "We need to track employee email addresses now!" You use `ALTER TABLE` to knock down a wall and add a brand new column to the existing structure.
- **The 3 Renovations**:
  - `ADD`: Build a new room (column).
  - `DROP COLUMN`: Demolish an existing room.
  - `ALTER COLUMN`: Change the purpose of a room (like changing a `VARCHAR` text column into an `INT` number column).

---

## 📖 STEP 2.5 — VOCABULARY & DEFINITIONS

- **UPDATE**: A DML command that changes existing data values inside the table without adding or removing any rows.
- **ALTER TABLE**: A DDL command that changes the actual structural blueprint of the table (like adding or removing a column).
- **Metadata**: Data about data. It doesn't tell you the employee names, but it tells you the structural details of the table (like what columns exist and what their data types are).
- **sp_help**: A built-in SQL Server stored procedure that reveals the metadata/blueprint of your table.

## 💻 STEP 3 — SQL SYNTAX & CODE EXAMPLES

### 1. The UPDATE Command (The Magical Eraser)
```sql
-- Example A: Safely updating a single target using the Sniper Scope (WHERE)
UPDATE emp 
SET city = 'Pune' 
WHERE empid = 1;

-- Example B: Updating multiple targets at once
UPDATE emp 
SET salary = 50000 
WHERE dept = 'HR';

-- Example C: Updating multiple columns at the exact same time (New!)
UPDATE emp
SET city = 'Mumbai', salary = 75000
WHERE empid = 105;

-- Example D: DANGEROUS MASS UPDATE! No WHERE clause! (New!)
UPDATE emp 
SET company_name = 'Google'; -- Everyone in the table now works for Google!
```

### 2. The ALTER TABLE Command (The House Renovator)
```sql
-- Example A: Building a new room (Adding a column)
ALTER TABLE emp 
ADD dob VARCHAR(10);

-- Example B: Demolishing a room (Dropping a column)
ALTER TABLE emp 
DROP COLUMN dob;

-- Example C: Changing the room type (Modifying data type)
ALTER TABLE emp 
ALTER COLUMN dob DATE;

-- Example D: Adding multiple columns at the same time (New!)
ALTER TABLE emp
ADD email VARCHAR(50), phone_number INT;
```

### 3. Inspecting Metadata (Looking at the Blueprint)
```sql
-- Example A: Ask the database to show you the blueprint of the table
EXEC sp_help 'emp';
-- OR simply:
sp_help 'emp';
```

## ⚠️ STEP 5 — COMMON MISTAKES & DEBUGGING

### Mistake 1: Forgetting the COLUMN keyword when dropping
```sql
-- ❌ BUGGY QUERY: Missing the word COLUMN
ALTER TABLE emp DROP dob;
```
- **✔️ CORRECTION**: The database gets confused. Are you dropping a constraint? An index? A column? You must be specific!
```sql
ALTER TABLE emp DROP COLUMN dob;
```

### Mistake 2: Mixing up UPDATE and ALTER TABLE
```sql
-- ❌ BUGGY QUERY: Trying to use ALTER to change a person's city
ALTER TABLE emp SET city = 'Pune' WHERE id = 1;
```
- **✔️ CORRECTION**: `ALTER TABLE` only touches the walls (structure). To touch the data, use `UPDATE`!
```sql
UPDATE emp SET city = 'Pune' WHERE id = 1;
```

## 🌐 STEP 6 — REAL-WORLD DATA ENGINEERING APPLICATION

### Scenario: The GDPR Data Masking Request
In the real world, laws like GDPR or HIPAA require companies to delete or mask personal user data if the user requests it.
- **The Challenge**: A user wants you to delete their phone number, but keep their account active.
- **The Solution**: You don't use `DELETE` (because that destroys the whole row). Instead, Data Engineers use `UPDATE` to scrub the specific data point:
```sql
UPDATE Customers 
SET PhoneNumber = NULL 
WHERE CustomerID = 99281;
```
