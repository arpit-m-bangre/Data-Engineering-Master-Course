## STEP 1 — QUICK RECALL

### Recall Questions
1. How do you construct a `LIKE` pattern for a string starting with 'A', ending with 'n', and having EXACTLY 6 characters?
2. What is the difference between `LIKE '%gmail%'` vs `NOT LIKE '%gmail%'`?
3. How can you verify that a string contains BOTH alphabetical letters AND numeric digits without regular expressions?

### Answers & Explanations
1. **Exact 6-character pattern**: `LIKE 'A____n'` (A + 4 underscores + n = 6 characters).
2. **`NOT LIKE`**: `LIKE '%gmail%'` returns rows containing 'gmail'; `NOT LIKE '%gmail%'` returns rows where 'gmail' does NOT appear.
3. **Alphanumeric check**: Combine two `LIKE` predicates: `EmpName LIKE '%[A-Za-z]%' AND EmpName LIKE '%[0-9]%'`.

### Task-by-Task Problem Breakdown

#### Task 1: Salary Exclusion & Department Filter
Retrieve employees whose salary is NOT between 40,000 and 70,000, BUT department is either 'HR' or 'IT'.
```sql
SELECT * FROM Employee1
WHERE Salary NOT BETWEEN 40000 AND 70000
  AND dept IN ('HR', 'IT');
```

#### Task 2: Vowel Filter in Names
Display employee names that contain any vowels.
```sql
SELECT * FROM Employee1
WHERE EmpName LIKE '%A%' OR EmpName LIKE '%E%' OR EmpName LIKE '%I%'
   OR EmpName LIKE '%O%' OR EmpName LIKE '%U%'
   OR EmpName LIKE '%a%' OR EmpName LIKE '%e%' OR EmpName LIKE '%i%'
   OR EmpName LIKE '%o%' OR EmpName LIKE '%u%';
```

#### Task 3: Range Check Without `BETWEEN` or `LIKE`
Display students whose marks are between 50 and 80 without using `BETWEEN` or `LIKE`.
```sql
SELECT * FROM StudentInfo
WHERE Marks >= 50 AND Marks <= 80;
```

## STEP 5 — COMMON MISTAKES & DEBUGGING

### Buggy Query
```sql
-- Bug: Using OR instead of AND for alphanumeric check
SELECT * FROM Employee1 
WHERE EmpName LIKE '%[A-Za-z]%' 
   OR EmpName LIKE '%[0-9]%';
```
- **Correction**: `OR` returns names that contain letters OR numbers (which matches almost everything). To require BOTH letters AND numbers, you must use `AND`.
```sql
SELECT * FROM Employee1 
WHERE EmpName LIKE '%[A-Za-z]%' 
  AND EmpName LIKE '%[0-9]%';
```
