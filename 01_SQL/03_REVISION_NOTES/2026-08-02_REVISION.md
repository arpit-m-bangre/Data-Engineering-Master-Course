## 🧠 STEP 1 — QUICK RECALL

### ❓ Recall Questions
1. Does the `<>` (Not Equal) operator evaluate `NULL` values as true?
2. What is the difference between `%` and `_` in `LIKE` pattern matching?
3. How does `BETWEEN 2000 AND 6000` handle range boundaries (inclusive or exclusive)?
4. What wildcard pattern matches any string starting with letters A through M?

### 🗝️ Answers & Explanations
1. **`<>` and `NULL`**: No! Think of `NULL` as a ghost. You can't ask "Are you not equal to Bob?" to a ghost. The database just gets confused (`UNKNOWN`). To find ghosts, you must specifically say `IS NULL` or `IS NOT NULL`.
2. **Wildcards**: The percent sign `%` is a giant net that catches **zero or more characters** of any length. The underscore `_` is a tiny hook that catches **exactly one single character**.
3. **`BETWEEN` Boundaries**: `BETWEEN` is **inclusive**, like saying "Everyone from age 18 to 21, including 18 and 21!"
4. **Range Wildcard**: `LIKE '[A-M]%'`.

## 🧠 STEP 2 — CONCEPT UNDERSTANDING

### Topic 1: The `WHERE` Clause (The Club Bouncer)
- **What it means**: The `WHERE` clause is the strict bouncer at the door of your data club. It checks every single row of data and says, "Do you meet the criteria? If yes, come in. If no, go home."
- **Why/When used**: Used whenever you only want to look at specific rows (like only employees from 'HR').

### Topic 2: Logical Operators — `AND` vs `OR` (Strict vs Chill Parents)
- **What it means**:
  - `AND` (The Strict Parent): ALL rules must be followed! "You can go out if you finish your homework `AND` clean your room." If one is false, the answer is NO.
  - `OR` (The Chill Parent): Just ONE rule needs to be met! "You can get ice cream if you eat your veggies `OR` wash the dishes." As long as one is true, you're good!

### Topic 3: `LIKE` Pattern Matching & Wildcards (The Police Sketch Artist)
- **What it means**: Sometimes you don't know the exact name, you just know what it *looks like*. Wildcards help you describe the pattern.
- **Wildcard Cheat Sheet**:
  - `'A%'`: Starts with A (and anything after).
  - `'%h'`: Ends with h.
  - `'%A%'`: Contains A anywhere inside.
  - `'R%A'`: Starts with R and ends with A.
  - `'_m%'`: The exact second character is m.
  - `'[A,M]%'`: Starts with either A or M specifically.
  - `'[A-Z]%'`: Starts with any letter from A through Z.
  - `'[^A-Z]%'`: Does NOT start with any letter from A through Z (The `^` means NOT).

## 📖 STEP 2.5 — VOCABULARY & DEFINITIONS

- **Clause**: A distinct part of a SQL statement that performs a specific function (like `WHERE` for filtering, `SELECT` for displaying).
- **Predicate**: The condition being checked in a `WHERE` clause that results in True, False, or Unknown (e.g., `salary > 5000`).
- **Relational Operator**: Math symbols used to compare two things (like `=`, `<`, `>`, `<>`).
- **Wildcard**: A special symbol (like `%` or `_`) used to represent one or more missing characters in a text search.

## 💻 STEP 3 — SQL SYNTAX & CODE EXAMPLES

```sql
-- 1. Comparison & Nullability (The Bouncer Checking IDs)
SELECT * FROM employee1 WHERE dept = 'HR';
SELECT * FROM employee1 WHERE dept <> 'HR'; -- Everyone who is NOT in HR
SELECT * FROM employee1 WHERE dept IS NULL; -- Finding the ghosts (missing departments)

-- NEW: Advanced numerical comparisons
SELECT * FROM employee1 WHERE salary >= 50000; -- High earners
SELECT * FROM employee1 WHERE age <= 25;       -- Young employees

-- 2. IN and BETWEEN (The VIP List & Age Brackets)
SELECT * FROM employee1 WHERE dept IN ('HR', 'Entc'); -- Are you on the VIP list?
SELECT * FROM employee1 WHERE salary BETWEEN 2000 AND 6000; -- Are you in this bracket?

-- NEW: Opposite filters using NOT
SELECT * FROM employee1 WHERE dept NOT IN ('IT', 'Finance'); -- Banning specific departments
SELECT * FROM employee1 WHERE salary NOT BETWEEN 1000 AND 2000; -- Excluding a specific bracket

-- 3. LIKE Patterns (The Detective Search)
SELECT * FROM employee1 WHERE empname LIKE 'A%'; -- Names starting with A
SELECT * FROM employee1 WHERE empname LIKE '_m%'; -- Second letter is exactly 'm'
SELECT * FROM employee1 WHERE empname LIKE '[^A-Z]%'; -- Names that start with a weird character/number

-- NEW: Complex Detective Combinations
SELECT * FROM employee1 WHERE empname LIKE '%son%'; -- Anyone whose name contains 'son' (e.g., Johnson, Mason)
SELECT * FROM employee1 WHERE phone_number LIKE '555-%'; -- Finding specific area codes
```

## ⚠️ STEP 5 — COMMON MISTAKES & DEBUGGING

### Mistake 1: Trying to use '=' with NULL
```sql
-- ❌ BUGGY QUERY: You can't use an equals sign on a ghost!
SELECT * FROM employee1 WHERE dept = NULL;
```
- **✔️ CORRECTION**: `dept = NULL` will return 0 rows. Always use `IS NULL`.
```sql
SELECT * FROM employee1 WHERE dept IS NULL;
```

### Mistake 2: Forgetting Quotes in BETWEEN
```sql
-- ❌ BUGGY QUERY: A and M are naked! SQL thinks they are columns.
SELECT * FROM employee1 WHERE empname BETWEEN A AND M;
```
- **✔️ CORRECTION**: Text must always wear its jacket (single quotes `'A'` and `'M'`).
```sql
SELECT * FROM employee1 WHERE empname BETWEEN 'A' AND 'M';
```
