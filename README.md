## 🚀 SQL Data Engineering Projects Overview (`01_SQL/06_PROJECTS/`)

1. **[PROJECT 1: E-Commerce Sales & Customer Analytics Pipeline](./01_SQL/06_PROJECTS/PROJECT1.SQL)**  
   - *Topics*: DDL/DML, Table Creation, Selective Ingestion, Arithmetic Operators, Computed Projection Aliases, `UPDATE`, `DELETE`, `WHERE`, `LIKE` Wildcards.
2. **[PROJECT 2: Healthcare Hospital Admissions & Billing Pipeline](./01_SQL/06_PROJECTS/PROJECT2.SQL)**  
   - *Topics*: Schema Evolution (`ALTER TABLE ADD`/`DROP`/`ALTER COLUMN`), `sp_rename`, `DELETE` vs `TRUNCATE`, Aggregate Functions (`MIN`, `MAX`, `SUM`, `AVG`, `COUNT`), `NULL` Rules, `DISTINCT`, `TOP N`.
3. **[PROJECT 3: Banking Transaction Audit & Fraud Detection System](./01_SQL/06_PROJECTS/PROJECT3.SQL)**  
   - *Topics*: SQL Clause Execution Sequence (`FROM` $\rightarrow$ `WHERE` $\rightarrow$ `GROUP BY` $\rightarrow$ `HAVING` $\rightarrow$ `SELECT` $\rightarrow$ `ORDER BY`), `WHERE` vs `HAVING`, Multi-Column Grouping & Sorting, Scoping Rules.
4. **[PROJECT 4: HR Enterprise Payroll & Data Validation Engine](./01_SQL/06_PROJECTS/PROJECT4.SQL)**  
   - *Topics*: SQL Constraints (`PRIMARY KEY`, `UNIQUE`, `NOT NULL`, `CHECK`, `DEFAULT`), `IDENTITY` Auto-Increment, 10 Data Insertion Patterns, Constraint Error Tracing.
5. **[PROJECT 5: Retail Supply Chain & Referential Integrity Architecture](./01_SQL/06_PROJECTS/PROJECT5.SQL)**  
   - *Topics*: Multi-Tier Relational Data Warehouse, `FOREIGN KEY` Relational Architecture, Parent vs Child Table Destruction Rules (`DELETE`, `TRUNCATE`, `DROP`), Cascading Teardown.
