## SECTION 2: PARSER CONTRACT — VERCEL DASHBOARD COMPLIANCE

The `DASHBOARD/src/main.js` parser reads `TODAYS_TASKS.txt` using these strict rules:

### 2.1 Task Card Detection Regex
```javascript
/^\[([xX\s\-]?)\]\s*([\d:]+\s*(?:AM|PM)\s*[-–]\s*[\d:]+\s*(?:AM|PM))\s*:\s*(.+)$/
```

### 2.2 Status Classification Logic
| Marker | Condition | Parsed As | UI Card Style |
| :---: | :--- | :--- | :--- |
| `[x]` | Any text | `done` | ✅ Green completed card |
| `[ ]` | Any text | `pending` | ⬜ White active sprint card |
| `[-]` | Contains break keyword | `break` | ☕ Dimmed recharge card |
| `[-]` | No break keyword | `deferred` | ⏳ Yellow deferred card |

### 2.3 Break Keywords
```text
break | lunch | dinner | tea | relax | recharge | market | family | nap | sleep | meal | friends | walk
```

### 2.4 Sub-Bullet Detection Regex
```javascript
/^\s{4}->\s(.+)$/
```
*(Must be indented with exactly 4 spaces followed by `-> `)*.

---

## SECTION 3: SYNTAX RULES (NON-NEGOTIABLE)

1. **Card Header Format:** `[STATUS] HH:MM AM - HH:MM PM : Sprint Title`
2. **Sub-Bullets:** Exactly 4 spaces + `-> ` (`    -> Description`)
3. **Breaks:** Use `[-]` with break keyword in title.
4. **Deferred:** Use `[-]` without break keyword.
5. **Done:** Use `[x]` (lowercase/uppercase).
6. **Pending:** Use `[ ]` (single space inside brackets).
7. **Dividers:** Outer box `====================================================================` (68 chars); section dividers `--------------------------------------------------------------------`.

```text

❌ [X ] 10:00 AM : Task (no closing time)
❌   -> Detail (2-space indent)
❌ 	-> Detail (tab indent)
❌ -> Detail (no indent)
❌ [-] Sprint 3 (Deferred) (no time range)
```
