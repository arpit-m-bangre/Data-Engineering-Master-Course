## 🚀 4-STEP STRATEGY TO LAND 15 LPA – 35+ LPA INTERVIEWS

### Step 1: Optimize Your GitHub Portfolio as a Proof-of-Work Engine
- Maintain your daily commit streak (the **200-Day Commit Streak**).
- Structure your repository with clear module numbers (`01_SQL`, `02_PYTHON`, `03_ETL`, `04_PYSPARK`, `05_DWH`).
- Include professional Markdown READMEs with architectural Mermaid diagrams for all your projects.

### Step 2: Employee Referral Hunting (10x Better than Direct Portals)
- Find **Senior Data Engineers, Lead Architects, or Engineering Managers** working at the target companies above on LinkedIn.
- Send a personalized 3-point note:
  > *"Hi [Name], I came across the Data Engineer role at [Company]. I specialize in scalable SQL query optimization, distributed PySpark pipelines, and cloud lakehouse architecture. I have built 5+ end-to-end production pipelines on GitHub with clean commits. Would you be open to reviewing my work and referring me?"*

### Step 3: Master the 3-Layer Live Coding Round
1. **Round 1 (SQL Drill):** 2 to 3 live SQL questions involving complex JOINS, Window functions, Self-Joins, and date arithmetic.
2. **Round 2 (Python & Data Cleansing):** 1 LeetCode Medium problem + 1 data transformation task with edge cases (handling NULLs, duplicates, malformed JSON).
3. **Round 3 (System Design & Data Architecture):** Design an end-to-end batch/streaming data pipeline (e.g., *Design a Real-Time Ride Fare Ingestion Engine for Uber* or *Design a Daily Sales Data Warehouse for Walmart*).

### Step 4: Salary Negotiation Multiplier
- Never reveal your current budget/salary on the first HR screening call.
- State: *"Based on market benchmarks for Data Engineers working with modern distributed stacks (PySpark, SQL, Cloud Lakehouse) and my demonstrated project portfolio, I am targeting ₹X LPA to ₹Y LPA."*
