## 🔑 5 CORE PRINCIPLES OF THE COURSE ECOSYSTEM

### 1. 100% Data Preservation & Zero Content Loss
No technical concept, query logic, docstring, faculty note, or interview trap is ever removed or simplified. Raw class notes are restructured into clean, standardized formats while preserving 100% of technical depth.

### 2. Strict SQL Formatting & Keyword Capitalization
All SQL code blocks maintain 100% uppercase keywords (`SELECT`, `FROM`, `WHERE`, `CREATE TABLE`, `ALTER TABLE`, `UPDATE`, `DELETE`, `TRUNCATE`, `DROP`, `JOIN`, `WITH`, etc.) and multi-line clause indentations.

### 3. 3-Stage Learning Mastery Rule
Every topic follows a strict 3-stage mastery rule:
$$\text{Revision Notes (.md)} \longrightarrow \text{Index-Wise Practice Questions (.SQL)} \longrightarrow \text{Data Engineering Projects (.SQL)}$$

### 4. Hands-On SSMS Drill Design
Practice question sets inside `05_INDEX_WISE_QUESTIONS/` are formatted inside comment blocks with blank space lines below `-- Write your SQL Query below:` to enable hands-on query writing from scratch in SQL Server Management Studio (SSMS).

### 5. Automated Multi-File Synchronization
Whenever a new raw class note is added, the system automatically updates all 6 SQL subdirectories AND synchronizes `MASTER_LEARNING_TRACKER.txt`, `METRICS_AND_STATISTICS.json`, `CONCEPT_MASTERY_HEATMAP.md`, `LEARNING_DIARY.txt`, and `README.md`.

### 6. Directory Security & Anti-Teardown Safeguard
All root module folders (`00_SYLLABUS`, `01_SQL`, `02_PYTHON`, `03_ETL_DATA_PIPELINES`, `04_PYSPARK_BIG_DATA`, `05_DATA_WAREHOUSING`, `06_CLOUD_ENGINEERING`, `07_ORCHESTRATION`, `LEARNING_DIARY`, `.agents`) are strictly protected against recursive directory deletion (`rm -rf`, `git clean -fdx`). Internal code files can be freely altered and updated, while folder structures remain permanently safe.
