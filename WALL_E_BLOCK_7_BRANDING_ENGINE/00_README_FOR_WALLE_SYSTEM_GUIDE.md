### 1. PART 1: LINKEDIN AUTHORITY ENGINE (0-30 MINS)

#### A. Draft & Publish Daily Post:
- **Campaign Tag:** `#180DaysOfDataEngineering`
- **Post Structure:**
  1. **Hook (Line 1-2):** A punchy, counter-intuitive technical statement or common misconception (e.g., *"Why GROUP BY fails before SELECT: The Execution Order Truth"*).
  2. **The Problem / Mechanism (Lines 3-6):** Explain the relational engine internals (RAM, disk spill, execution tree, parsing order).
  3. **The Solution & SQL Code (Fenced block):** Clean, uppercase keywords (`SELECT`, `FROM`, `WHERE`, `GROUP BY`, `HAVING`).
  4. **The Senior Architect Takeaway:** How this saves cluster compute, reduces I/O, or prevents production bugs.
  5. **Call to Action (CTA):** Ask a thoughtful technical question to trigger comments from Lead Data Engineers.

#### B. The 5-7 Tier-1 Targeted Outreach Rule:
- Send **5 to 7 personalized connection requests daily** to:
  - **Tier 1A Titans:** Google, Microsoft, Amazon, Meta, Apple, Netflix.
  - **Tier 1B Top GCCs:** Walmart Global Tech, Target Enterprise, Lowe's India, J.P. Morgan, Goldman Sachs.
  - **Tier 1C High-Scale Tech:** Swiggy, Zomato, Uber, Zepto, Razorpay, CRED, PhonePe.
- **Target Profiles:** *Senior Data Engineer, Lead Data Engineer, Staff Database Architect, Engineering Manager (Data)*.
- **Connection Note Formula:**
  > *"Hi [Name], loved your recent post on distributed data pipelines. I'm currently documenting 180 days of deep relational internals, query optimization, and PySpark scaling. Would love to connect and follow your engineering journey!"*

#### C. The 3-Comment Architect Engagement Rule:
- Leave **3 insightful technical comments** on posts by Senior Staff DEs or Tech Leads.
- Never write *"Great post!"* or *"Thanks for sharing"*.
- Add an architectural nuance, mention index page splits, execution plan cost, or trade-offs.
