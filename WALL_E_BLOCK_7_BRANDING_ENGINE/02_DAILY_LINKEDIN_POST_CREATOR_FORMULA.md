Maintain the same restrained color language across the entire series.

### BLACK
General text, outlines, arrows, labels, structure.

### GREEN

# LINKEDIN POST STRUCTURE

Use this general structure:

### HOOK

Short and strong.

Create curiosity.

Prefer a statement that creates a knowledge gap.

Example style:

"Most people write JOINs every day.

Almost nobody knows what the database actually does with them."

---

### EXPLANATION

Start simple.

Explain the concept in plain language.

Use short paragraphs.

---

### TECHNICAL CORE

Explain the important mechanics.

Use bullets when useful.

Use code blocks when the post format calls for code.

Keep examples practical.

---

### IMPORTANT INSIGHT

Explain the thing that experienced engineers know but beginners often miss.

This should be the "aha" moment.

---

### TAKEAWAY

End with one memorable sentence.

It should be short enough that someone could remember it later.

---

### HASHTAGS

# HUMANIZATION RULE

Use these naturally, not mechanically.
